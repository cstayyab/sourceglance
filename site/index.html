Your issues, pull requests and boards, one glance away.

Source Glance puts what's assigned to you on GitHub and GitLab, across all your accounts and self-hosted instances, in the top bar, on your desktop and in its own searchable window. Comment, close, relabel and move cards without opening a browser.

Everything assigned to you, without the tab hunt

Top-bar buttons

Issues, Pull requests and Projects as one tinted group or as tabs, each with its live count. Filter by label, collapse the repositories you don't need right now; closed items are counted at the bottom. Menus keep a steady width sized to your screen.

Act from the menu

Comment, close or reopen, edit assignees and labels, and move items between statuses on your project boards. In the window, preview an item with its comments and reactions, edit its description, and add labels and assignees as chips.

Every account, self-hosted too

Add several GitHub and GitLab accounts, each with its own collapsible section. A guided setup connects GitHub Enterprise Server and GitLab self-managed, and counts add up across them all.

Main window

All Tasks puts everything assigned to you in one list, filtered by kind, account, label or assignee, and each list filters by label and assignee. Your lists and settings sit in a sidebar, and it's an app of its own: Source Glance in the dock and in Alt+Tab.

Desktop widgets

Summary, Issues, Pull requests and Projects cards on your desktop. Drag them anywhere, set their opacity, and set the wallpaper they're made for in one click, with Reset to put yours back.

Private by design

On github.com, sign in through a GitHub App limited to issues, pull requests and projects: no code access. Tokens stay in the GNOME keyring, and self-hosted instances need HTTPS unless they're on your local network.

Search your lists

One box, always on the right of the window's title bar, filters issues, pull requests and project items by title, repo, number, label or person, with match counts. Clear it to see everything again.

One-click updates

A notification at login says when a new version is out, with what's new. Install downloads the new Setup, checks its SHA-256 checksum and updates Source Glance, with no need to log out.

Open source

MIT licensed. Public repositories you don't own show up without any setup. Report an issue or contribute.

Install in three steps

  1. Download Setup

    Source Glance Setup for Intel/AMD works on most PCs; there's also a build for ARM.

  2. Allow it to run

    In Files, right-click the download, choose Properties and turn on Executable as Program.

  3. Run the wizard

    Double-click it and follow the steps. Run it again any time to repair or remove Source Glance.

Check the download (recommended)

Download SHA256SUMS into the same folder and run:

sha256sum --check --ignore-missing SHA256SUMS

Every release is built by GitHub Actions with a provenance attestation. See the install guide.

Needs GNOME Shell 46–50 (Ubuntu 24.04 or newer) and a GitHub or GitLab account.

Update, repair or remove

One Setup file does it all: install, update, repair or remove. Run the latest Setup and it updates the Source Glance you have in place, keeping your settings and sign-ins. The new version starts right away, with no need to log out.

Easier still: when a newer version is out, a notification says so when you log in, with short release notes; Install starts the update. The window also shows Update available in its title bar. Click it and Source Glance downloads the new Setup, checks it against the release's SHA-256 checksums and opens it; when Setup finishes, the window reopens on the new version. Turn the check off in Settings → System Start. (Coming from v0.2.0 or earlier, log out once after updating.)

Get involved

Source Glance is open source. Found a bug or have an idea? Tell us, or fork the repository and send a pull request.

Report an issue Fork on GitHub
  1. Fork the repository and clone your fork.
  2. Create a branch, make your change, and run make lint and make test.
  3. Push to your fork and open a pull request against main.
